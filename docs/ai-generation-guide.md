# AI Image Generation Guide for Faeweel Flipbook Movie

## Overview

This guide explains how to use AI image generation tools (like DALL-E, Midjourney, Stable Diffusion, or similar) to create the 120 frames for the Faeweel angel flipbook movie.

## Recommended Workflow

### Step 1: Choose Your AI Tool

**Option A: DALL-E 3 (via ChatGPT Plus or API)**
- Best for: Consistent character design, precise following of descriptions
- Pros: Excellent at understanding detailed prompts, good consistency
- Cons: Rate limits, cost per image

**Option B: Midjourney**
- Best for: Artistic, ethereal, beautiful imagery
- Pros: Stunning visual quality, good for angelic/mystical aesthetic
- Cons: Less precise control, requires Discord, subscription

**Option C: Stable Diffusion (Local or Online)**
- Best for: Full control, unlimited generation, custom models
- Pros: Free if run locally, can fine-tune, no rate limits
- Cons: Requires technical setup, needs good GPU

**Option D: Adobe Firefly**
- Best for: Commercial use, integration with Adobe tools
- Pros: Commercial-safe, good quality, Adobe ecosystem
- Cons: Subscription required

**Recommended: Start with DALL-E 3 for consistency, then refine with other tools**

## Step 6: Maintaining Consistency

### Character Consistency Techniques

**1. Reference Image Method:**
- Generate character reference sheet first
- Include phrase: "Same character as reference image" in subsequent prompts
- Some tools (DALL-E 3, Midjourney with /describe) support this

**2. Seed Method (Stable Diffusion):**
- Use same seed number for character across frames
- Change only pose/action in prompt
- Keep lighting and style parameters identical

**3. LoRA/Fine-tuning (Advanced):**
- Train custom LoRA on character references
- Use trained model for all frames
- Best consistency, requires technical knowledge

**4. Detailed Description Method:**
- Copy-paste exact character description in every prompt
- Only change action/pose portions
- Most accessible but requires careful prompting

## Step 7: Post-Processing and Assembly

### Tools for Refinement

**Image Editing:**
- Photoshop or GIMP for cleanup
- Adjust brightness/contrast for consistency
- Color correction across frames
- Remove artifacts

**Animation Assembly:**
- After Effects for smooth frame sequencing
- Premiere Pro for video editing
- Blender for 3D-like transitions
- Free option: DaVinci Resolve

**Flipbook Creation:**
- Print frames on card stock
- Use online flipbook makers
- Create GIF using GIMP or Photoshop
- Create video slideshow

### Timing and Frame Rate

**For Video:**
- 24 fps (cinematic): Each frame appears for ~0.042 seconds
- 30 fps (standard): Each frame appears for ~0.033 seconds
- 12 fps (animated feel): Each frame appears for ~0.083 seconds

**Based on flipbook script timing:**
- Slow sequences: Hold frames longer (2-3 times)
- Medium sequences: Standard timing
- Fast sequences: Single frame each

**Suggested approach:**
- Generate all 120 unique frames
- Duplicate slow-motion frames in editing
- 120 frames at 12 fps = 10 seconds
- With duplicates for timing = 3-5 minutes final length

## Step 8: Batch Generation Workflow

### Using ChatGPT (DALL-E 3)

1. **Session 1: References**
   - Generate character reference sheet for Faeweel
   - Generate each of the Seven Sons
   - Generate Kick and Jack Islands
   - Save all with clear filenames

2. **Session 2-5: Keyframes**
   - Generate 3-4 keyframes per session
   - Reference previous images: "Use same art style as [describe previous image]"
   - Save and organize by frame number

3. **Session 6+: In-between frames**
   - Fill gaps between keyframes
   - "Show transition from [Frame X] to [Frame Y]"

### Using Midjourney

```
Example progression:

Prompt 1 (Character reference):
/imagine ethereal angelic being, six wings, glowing flywheel at chest, translucent form, white to blue gradient wings, gentle face, mystical digital art, character design sheet --ar 16:9 --style raw --v 6

Prompt 2 (Use image URL from Prompt 1):
/imagine [URL] same character, wings spread wide, hovering in dark space, peaceful pose --ar 16:9 --style raw --v 6

Prompt 3 (Build on previous):
/imagine [URL] same character, active flying pose, data particles flowing --ar 16:9 --style raw --v 6
```

### Using Stable Diffusion (Automatic1111 or ComfyUI)

1. **Find/create checkpoint:**
   - Use model like "DreamShaper" or "Realistic Vision" for base
   - Or find fantasy/ethereal-focused model

2. **Positive prompt template:**
```
(masterpiece, best quality, high detail), ethereal angelic being, six translucent wings, glowing golden flywheel at chest, gentle face with shimmering eyes, soft smile, white to blue gradient wings, floating light particles, hovering in dark cosmic void with stars, mystical digital art, luminous, soft lighting, [SPECIFIC ACTION/POSE], cinematicphoto, 8k, detailed

Steps: 40
Sampler: DPM++ 2M Karras
CFG Scale: 7
Seed: [KEEP SAME FOR CHARACTER CONSISTENCY]
Size: 1920x1080 or 1024x1024
```

3. **Negative prompt:**
```
low quality, blurry, distorted, ugly, deformed, multiple heads, extra limbs, text, watermark, signature, harsh shadows, over-saturated, realistic human, solid wings, traditional angel, photograph
```

4. **Batch process:**
   - Create prompt file with all 120 frame prompts
   - Use same seed for character
   - Vary only action/composition
   - Batch generate overnight

**Tools like:**
- Runway Gen-2
- Pika Labs
- Stable Diffusion Video

**Process:**
1. Generate keyframes as images
2. Use AI video to interpolate between keyframes
3. Less control but faster
4. May lose some detail

### 3D Pipeline

1. Model Faeweel and Sons in Blender
2. Use AI-generated images as texture references
3. Pose and render each frame
4. Apply post-processing for ethereal effect
5. Most control, highest effort

## Final Assembly Instructions

### Creating the Video

1. **Import frames** into video editor in sequence
2. **Set duration** per frame based on timing guide
3. **Add transitions** (crossfade 0.1-0.2s between frames)
4. **Add text overlays** for captions from script
5. **Add soundtrack** (see flipbook script for suggestions)
6. **Add sound effects** for key moments (kick, merger, etc.)
7. **Color grade** for consistency across all frames
8. **Export** at 1080p, H.264, 24fps or 30fps

### Creating Physical Flipbook

1. **Print frames** on 110lb cardstock
2. **Cut to uniform size** (3x5 inches or 4x6 inches)
3. **Number each frame** in corner
4. **Align using registration marks**
5. **Clip or bind** on left edge
6. **Test flip** and adjust if needed

### Creating GIF

1. **Open frames in Photoshop or GIMP**
2. **File > Scripts > Load Files into Stack**
3. **Window > Timeline**
4. **Create Frame Animation**
5. **Set frame delays** (0.05-0.15s each)
6. **Set to loop forever**
7. **Export for Web** (optimize for file size)

## Troubleshooting Common Issues

### Problem: Characters look different frame to frame

**Solution:**
- Use reference image method
- Include more specific details in prompt
- Lock in seed (Stable Diffusion)
- Consider using img2img for variations

### Problem: Background changes unexpectedly

**Solution:**
- Include background description in every prompt
- "Consistent dark void background" phrase
- Generate background separately and composite

### Problem: Colors don't match

**Solution:**
- Include hex codes in every prompt
- Post-process color correction
- Create color grading LUT to apply uniformly

### Problem: AI adds unwanted elements

**Solution:**
- Use negative prompts (Stable Diffusion)
- Be more specific about what NOT to include
- Edit out in post-production
- Regenerate with clearer prompt

### Problem: Lost mystical/ethereal feel

**Solution:**
- Include "ethereal, mystical, luminous, soft glow" in every prompt
- Reference artists known for ethereal work
- Add "dreamlike, magical, transcendent" keywords
